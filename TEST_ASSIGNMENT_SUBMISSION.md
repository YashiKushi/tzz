## 📄 Часть 1. Набросок продукта (Product Blueprint)

### 1.1. Какую проблему решаем и для кого
- **Целевая аудитория:** Малые и средние диджитал-агентства, веб-студии, арбитражные команды и фрилансеры.
- **Проблема:** Лиды приходят из несинхронизированных каналов (Telegram-боты, личные аккаунты менеджеров в TG, звонки, рекомендации). Заявки теряются, нет единого статуса обработки, отсутствует тегирование по типу задачи и приоритету, менеджеры забывают перезванивать.
- **Решение:** **Agency LeadFlow CRM** — сверхбыстрая веб-CRM система с автоматическим сбором заявок из Telegram, наглядной Канбан-воронкой, гибкой системой тегов и мгновенными уведомлениями клиенту.

---

### 1.2. Контур и архитектура системы

```
[ Telegram Bot (Пошаговый диалог) ] -----\
[ Telegram Personal (Userbot Pyrogram) ] --+--> [ Node.js Express API ] --> [ DB JSON ]
[ Ручной ввод лида в CRM ] ------------/             | (Server-Sent Events)
                                                     v
                                        [ React Web App (CRM Board) ]
```

---

### 1.3. Что входит в MVP (Реализовано в текущей версии)

1. **Заявки из Telegram-бота (Пункт 1 ТЗ):**
   - Интерактивный диалог боту: Имя → Контакт → Описание задачи.
   - Заявка автоматически создается в базе и **моментально вылетает на экране менеджера** через Server-Sent Events (без F5).
   - Присвоение тегов `Telegram Bot` и `Новый лид`.

2. **Ручное добавление (Пункт 3 ТЗ):**
   - Полнофункциональная модалка добавления клиента (Имя, Телефон/TG, Запрос, Источник, Статус, Заметки, Кастомные теги).

3. **Теги и фильтрация (Пункт 4 ТЗ):**
   - Цветная идентификация тегов (`Telegram Bot`, `TG Личный`, `Manual`, `Hot`, `VIP`, `Разработка` и т.д.).
   - Панель быстрой фильтрации всей воронки в 1 клик по любому тегу.
   - Добавление любых собственных тегов на лету.

4. **Интерактивный Канбан & Таблица:**
   - 5 этапов воронки (`Новый` → `В контакте` → `Переговоры` → `Сделка` → `Отказ`).
   - При смене статуса на "Сделка" или "Переговоры" бот **отправляет авто-уведомление клиенту** в Telegram.

---

### 1.4. Подключение обычного Telegram (Пункт 2 ТЗ — Архитектурный план)

Для захвата сообщений из личного Telegram аккаунта сотрудника или агентства используется технология **Userbot (MTProto API)**:

1. **Воркер слушатель:** На сервере запускается скрипт на `Python` с библиотекой `Pyrogram` (или `Telethon`).
2. **Сессия:** Аккаунт единоразово авторизуется через `api_id` + `api_hash` с официального портала `my.telegram.org`.
3. **Фильтрация личных чатов:** Воркер ловит событие `filters.private & ~filters.me`.
4. **AI-экстрактор лидов (Gemini Flash / GPT-4o-mini):** Входящий текст сообщения передается в микро-LLM со следующим промптом:
   > *"Извлеки из текста входящего сообщения личного Telegram имя клиента, контакт и суть запроса. Сформируй JSON с рекомендуемыми тегами."*
5. **Интеграция с CRM:** Извлеченные данные отправляются POST-запросом на `/api/leads` со сгенерированным тегом `TG Личный`.

> 💡 **В MVP представлена рабочая симуляция:** В интерфейсе CRM расположена кнопка *"Симуляция TG Личный"*, воспроизводящая этот процесс с созданием готового лида.

## 🛠️ Часть 2. Короткий разбор (Инструменты & AI Промпты)

### 2.1. Порядок выполнения задачи
1. **Проектирование (30 мин):** Формулирование структуры данных `Lead` и `Tag`, выбор стека Node.js Express + React Vite + SSE.
2. **Бэкенд & Telegram Bot (1 час):** Создание файловой базы данных `db.js`, реализация диалогового Telegram-бота на `node-telegram-bot-api`, настройка SSE-шины событий.
3. **Фронтенд & UX (1.5 часа):** Создание темного Glassmorphism дизайна, Канбан-доски, таблицы, модалок и цветного тегирования.
4. **Документирование & Симулятор (30 мин):** Добавление вкладки просмотра Наброска и Разбора внутри CRM, написание генератора сообщений для HR.
