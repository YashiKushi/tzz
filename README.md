# ⚡ Agency LeadFlow CRM — Мини-CRM для заявок агентства

Мини-CRM система сбора и управления лидами из Telegram-бота, личных сообщений Telegram и ручного ввода с динамическим тегированием и real-time воронкой продаж.

---

## 🌟 Ключевые возможности (Выполнение ТЗ)

1. **🤖 Заявки из Telegram-бота (Обязательный пункт 1):**
   - Интерактивный диалоговый бот в 3 шага (Имя → Контакт → Запрос).
   - Мгновенное появление лида в CRM без перезагрузки страницы (через Server-Sent Events).
   - Автоматическое присвоение тегов `Telegram Bot` и `Новый лид`.

2. **💬 Подключение обычного Telegram (Пункт 2):**
   - Архитектурное описание подключения личного Telegram через MTProto API (`Pyrogram` / `Telethon`).
   - Встроенный интерактивный **Симулятор личного Telegram**, позволяющий в 1 клик проверить обработку личных сообщений в CRM.

3. **✍️ Ручное добавление лидов (Обязательный пункт 3):**
   - Удобная модальная форма для внесения клиентов, пришедших с альтернативных каналов (звонки, встречи, рекомендации).

4. **🏷️ Гибкая система тегов (Обязательный пункт 4):**
   - Цветные плашки тегов для визуального разделения каналов и типов задач.
   - Возможность добавления собственных кастомных тегов при создании/редактировании лида.
   - Панель быстрой фильтрации всей воронки по любому тегу за 1 клик.

5. **📊 Двухрежимное отображение воронки:**
   - **Канбан-доска:** 5 этапов (`Новый` → `В контакте` → `Переговоры` → `Сделка` → `Отказ`).
   - **Табличный список:** Компактное представление с полем поиска.

6. **📄 Встроенная документация & Сообщение для HR:**
   - Вкладка *"Набросок и Разбор"* в шапке CRM с полным текстом Наброска продукта, разбором ИИ-промптов и готовым текстом для отправки HR Анне (`@lav_arb`).

## 🛠️ Запуск проекта локально

### 1. Установка зависимостей
```bash
npm install
```

### 2. (Опционально) Настройка Telegram Бота
Создайте файл `.env` в корневой папке (или скопируйте `.env.example`):
```env
PORT=5000
TELEGRAM_BOT_TOKEN=123456789:Ваш_Токен_От_BotFather
```
*Если токен не указан, приложение будет работать в автономном режиме с поддержкой ручного добавления и симулятора.*

### 3. Запуск в режиме разработки
```bash
npm run dev
```
Откройте браузер по адресу: **http://localhost:3000** (или http://localhost:5000)

## 🚀 Деплой на живую ссылку (Render / Railway / Vercel)

### Однокликовый деплой на Render / Railway:
1. Загрузите код в ваш GitHub репозиторий.
2. Создайте новый **Web Service** на [Render.com](https://render.com) или [Railway.app](https://railway.app).
3. Укажите:
   - **Build Command:** `npm run build`
   - **Start Command:** `npm start`
   - **Environment Variables:** `TELEGRAM_BOT_TOKEN` = Ваш токен бота.
4. Сервер автоматически соберет React фронтенд и запустит бэкенд на живой ссылке!
